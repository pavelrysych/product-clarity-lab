# Product Clarity Lab

Static landing page for Product Clarity Lab, a UX and product growth partner offer for startups and product companies.

## Files

- `index.html` - page markup and content
- `styles.css` - responsive visual system and layout
- `script.js` - mobile menu and inquiry draft behavior
- `assets/` - site imagery

Open locally with any static server, for example:

```bash
python -m http.server 4173
```
